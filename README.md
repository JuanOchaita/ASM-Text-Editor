# ASM-Text-Editor
Aplicación en assembler x8086 que emula las capacidades básicas de un editor de texto.  Crear, editar y guardar archivos de textos.  Cada archivo debe de guardar el color de fondo deseado por el usuario, el texto ingresado, el color para cada carácter de texto y las imágenes que el usuario ya haya ingresado.
